# 🚀 Atividade — Fork, Push e Pull Request

## 🎯 Objetivo

Nesta atividade, você irá simular uma contribuição para um projeto de software utilizando o GitHub.

Você deverá trabalhar em uma cópia do projeto (**Fork**), realizar alterações, enviar suas modificações (**Push**) e solicitar que elas sejam analisadas por meio de um **Pull Request**.

### Fluxo da atividade

**Repositório original → Fork → Alteração → Commit → Push → Pull Request → Code Review**

---

## 📌 O desafio

O projeto possui um programa em Python que calcula a média das notas de uma turma.

Sua missão será melhorar esse programa sem alterar diretamente o repositório original.

Você deverá trabalhar exclusivamente no seu Fork.

---

## ✅ Requisitos

Sua contribuição deverá:

* melhorar a legibilidade do código;
* utilizar nomes de variáveis claros;
* tratar o caso em que a lista de notas esteja vazia;
* apresentar a média com duas casas decimais;
* manter o funcionamento correto do programa;
* adicionar um comentário relevante no código;
* atualizar este README informando quais melhorias foram realizadas.

---

## 🌿 Regras da contribuição

1. Faça um **Fork** deste repositório.
2. Trabalhe no seu próprio Fork.
3. Faça as alterações solicitadas.
4. Registre suas alterações com um **Commit**.
5. Faça o **Push** para o seu Fork.
6. Abra um **Pull Request** para o repositório original.
7. Explique no Pull Request o que foi alterado.
8. Aguarde o **Code Review**.
9. Caso sejam solicitadas alterações, corrija o código e faça novo Push.
10. Aguarde a nova análise.

---

## 💬 Pull Request

Na descrição do Pull Request, informe:

**O que foi alterado?**

Explique quais melhorias você realizou.

**Por que essas alterações foram realizadas?**

Explique como elas melhoraram o código.

**O que foi aprendido nesta atividade?**

Explique brevemente o que você aprendeu sobre Fork, Push e Pull Request.
